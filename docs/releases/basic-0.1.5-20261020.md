# basic / 0.1.5 基线

日期：2026-10-20（Asia/Shanghai）。固定标签：`basic-0.1.5-20261020`。

本次将当前本机版本纳入 `basic`，保留版本号 `0.1.5`，作为后续实验的共同起点。已有 `v0.1.5` 标签和公开历史保持原样。

## 收录内容

- 0.1.5 已有的文件夹歌单预设、每歌单 1000 首上限与自主超限处理，以及曲库、桥接和查看器边界修复。
- 首字母分组按歌曲名排列，中文歌名按拼音首字母归类；音乐档案主标题显示歌名、副标题显示歌手。
- 顶部统一检索入口随档案库和音乐库切换，音乐状态、搜索与播放控制集中到同一入口。
- 音乐搜索栏与上方留白收紧；表头、列表、播放器和底部状态分区明确，小窗口及竖屏保留滚动和播放操作。
- 对参考工程的学习笔记与上述功能的回归检查。

## 后续工作方式

`basic` 作为默认基线分支；后续开发在 `experimental` 或 `experiment/<主题>` 进行，达到验收条件后合入基线。详见 [开发约定](../DEVELOPMENT.md)。

本次只固化当前实现并建立分支约定，没有改变音乐行距默认值、播放策略或其他运行偏好。验证状态单独记录在 [basic 验证记录](../../verification/BASIC-BASELINE.md)，未执行的检查保持明确标注。
