## 1.2 相对 1.1 的变化（本次唯一改动：档案随音乐响度律动）

用户要求「档案能随音乐响度律动」。此前三种律动（原版／连续频谱／层叠流波）都由低、中、高频段分别驱动，波的位置随频段分布，没有一档跟随**整体响度**；本次新增第四种律动风格：

- `MusicBands` 增加 `loudness`：`SpectrumEnvelope` 把 128 样本频谱按感知权重折算为整体响度（`spectrumLoudness`：低频 bin 权重 1、中频 0.8、高频 0.45；软膝曲线 `1−e^(−4.2·rms)` 保留瞬态并让弱音可读）。包络快攻（约 45ms）慢放（约 0.4s），鼓点清晰、余韵不闪。浏览器内核（AnalyserNode 折叠）与 VLC 桥接（PCM 折叠）**共用同一份折算**。
- 新增律动风格 **响度律动**（`pulse`）：整阵随响度同步抬升，处于屏幕中央的档案位移略大（`loudness × (0.8 + 0.35·centre)`），节拍来时整组档案一起起伏；与原版／连续频谱／层叠流波并列于「设置 → 本地音乐 → MUSIC REACTION」，沿用既有无门限交叉淡入切换。
- **默认为响度律动**：新装默认 `pulse`；已保存过律动选择的用户保持原选择，可在设置中一键切换。壁纸宿主通路同步放行 `pulse`，`musicGain` 同样缩放 `loudness`。

## 恢复与使用

```powershell
cd RhineLabUI
npm ci
npm run build
node scripts/fetch-vlc.mjs          # 需要 VLC 内核时
启动终端.cmd                        # 网页
启动音乐服务.cmd "D:\你的音乐目录"     # VLC 播放内核
```

设置 → 本地音乐 → 播放内核选「VLC 桥接」，填入音乐服务窗口打印的端口与令牌；MUSIC REACTION 中确认律动方式为「响度律动」（新装默认）。

## 校验

包内 `备份清单-SHA256.txt` 记录每个文件的 SHA256：

```powershell
Get-Content 备份清单-SHA256.txt | ForEach-Object {
  $hash, $rel = $_ -split '  ', 2
  if ((Get-FileHash -LiteralPath $rel -Algorithm SHA256).Hash -ne $hash) { "不一致: $rel" }
}
```

注意：`RhineLabUI\.git\index` 是 git 索引缓存，核对时运行过 `git status` 会使其被 git 自行刷新，属正常现象；仓库完整性以 `git fsck`（0）与 `git log --decorate`（可见 `v1.2`/`v1.1`/`v1.0` 标签）为准。
