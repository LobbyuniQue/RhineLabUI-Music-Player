# 2.4 · 音乐播放与曲库稳定性

2026-10-10。在当前本地音乐与三维档案工程上修复先前审查的六项问题。

- 快速切歌、加载中暂停/停止及销毁均废弃旧播放请求，防止显示曲目与音源错位或停止后重新开始。
- 修正上一首/下一首按钮方向，浏览器和 VLC 采用相同顺序；VLC 离线时保留所选内核并显示离线状态。
- VLC 验证沿用目录维护中完成的自有进程树清理，并验证另一个独立 VLC 实例不受影响。
- 桥接事件流或状态请求断线时清空连接与播放状态，按原偏好恢复背景配乐；自动重连后刷新曲库和实际播放状态。主动断开或销毁取消重试。
- 封面按当前帧可见歌曲复用 255 个真实槽位，异步分配票号阻止旧图片回填。换曲库、重扫和还原同时更新面板、档案与源封面缓存。
- 档案位置使用独立行列坐标与记录编号，大分组不再与下一列槽位冲突；内置五列八档的几何位置保留。

新增定向回归接入 `npm run check`。实际环境、执行命令、结果与验证边界见 [音乐稳定性验证](../../verification/MUSIC-RELIABILITY.md)。
