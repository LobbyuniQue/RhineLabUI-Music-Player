# 0.1.5 · 歌单与稳定性更新

日期：2026-10-14（Asia/Shanghai）。基于 0.1.4，完成后独立备份并发布。

## 歌单

- 每歌单最多 1000 首，预设名称与文件夹对应关系，音乐面板下拉切换。
- 超限先询问自动分卷或自行整理；自动分卷保留全部歌曲，不移动、复制或删除文件。
- 只为当前卷读取歌曲元数据与封面，完整音频按播放请求读取。浏览器非当前卷只保留目录预设；VLC 缓存只对应当前目录与卷。
- 浏览器目录预设保存在本机；文件选择回退只在本次会话可用。VLC 成功切换后记忆目录与分卷，重启恢复。
- 完整动画仍保持黑条等待、揭示结束帧起播；简化动画仍就绪即播。

## 修复

- 曲库来源与索引一起提交，扫描失败、取消及旧读取回调不能混用歌曲文件。
- 重扫按真实歌曲 ID 恢复档案选择，不等长分组重建按钮，主检索按 240 条分批显示。
- 原生扫描共享同一任务，切换期间拒绝冲突请求；删除嵌入封面后清除旧缓存。
- 按 ID3 版本解析扩展头，避免标题、歌手、专辑及封面丢失。
- VLC 获取必须比对官方 SHA256；已有安装恢复当前位置记录，ZIP 解压路径检查覆盖同前缀兄弟目录。
- 360° 查看器使用实际时间，静止画面复用，保留模型、纹理、主题、相机与尺寸变化的重绘。
- 两套集成测试共用浏览器通信实现，保留各自等待时长和日志策略。

## 验证与限制

实际执行情况见 [歌单验证记录](../../verification/MUSIC-PLAYLISTS.md)。专项模拟、VLC 获取校验、协议测试、浏览器集成与 VLC UI 集成分别记录；历史通过不作为本轮结果。

本机完整检查和构建、真实 VLC 协议 12 项、浏览器 46/46、VLC UI 26/26 已通过。远端最终验证独立记录于 [发行页](https://github.com/LobbyuniQue/RhineLabUI-Music-Player/releases/tag/v0.1.5)。

分卷依据文件路径排序，文件增删或改名后范围可能变化。无头测试验证状态与交接时机，不替代声卡听感和 GPU 跑分。本轮未改造桌面宿主或离线发行包。
