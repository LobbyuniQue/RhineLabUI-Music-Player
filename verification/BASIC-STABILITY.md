# basic 0.1.5 稳定性实验

2026-11-22，Windows，Node.js 24.22.1。实验分支为 `experiment/basic-stability`，起点为 `basic-0.1.5-20261020`（`46e0c03`）。本轮处理 10 月 23 日基线检查中的 01–05 项。

| 报告编号 | 复核结果 |
| --- | --- |
| 01、05 · FLAC 标签与封面 | 解析时按元数据块边界取字节。截短图片后面的曲名仍可读，300 KiB 图片与后置标题读取完整。浏览器和 VLC 的旧缓存各经一次增量扫描，只重读 FLAC，第二次扫描可全部复用。 |
| 02 · VLC 定位 | 每次载入曲目获得一个播放标识。受理和执行定位请求时均核验身份，过期请求返回 HTTP 409。原生协议检查覆盖同曲重播后的旧定位、新定位和准备票据，桥接逻辑检查覆盖暂停后的定位。 |
| 03 · 跨库详情 | 在播放中的音乐详情切到档案库，重新打开档案详情可看到档案收藏按钮。再切回音乐库，两次切换都回到目标库概览，播放曲目 ID 保持一致。 |
| 04 · 目录授权 | 重新授予读取权限后，下一次成功读取即可清除失效标记，统计和恢复后的索引一致。验证采用可控制权限状态的目录句柄。 |
