# 音乐模型简化实验

日期：2026-10-23（Asia/Shanghai）。分支：`experimental`。对照起点：`basic-0.1.5-20261020` / `46e0c0374f05855ca53921db471e4aa7fe166478`。源码版本仍为 0.1.5。

## 行为与边界

- 音乐库默认启用简化；“设置 → 本地音乐 → MUSIC MODEL → 简化音乐档案（实验）”可关闭并保存选择。档案库保持完整模型。
- 只改变内部网格的 `visible`。保留 `Frosted_Polymer`、`Ivory_Edges`、`Titanium_Fasteners`、`Index_Inlay`、`Optical_Diffuser`、`Printed_Label` 及没有 surface 标记的动态 Canvas 标签。
- 省略光学内环、内部陶瓷和光学层，也省略精细雕刻、模压字样等附加几何。必要底板仍提供内底色及原有阴影。
- 主卡片与所有正在归位的副本同步更新；重新选中归位卡片沿用同一可见性策略。音乐 360° 查看器同样省略内构，并隐藏没有可见部件的装配图例；档案查看器恢复完整结构。
- 背景阵列仍使用原有五类表面，没有再次替换背景材质或删减覆盖范围。透射、清漆、灯光、后处理、相机、行距与动画实现沿用已有设置。
- 两条播放内核以及完整/简化动画的加载和起播时序保持原路径。
- 完整 GLB 仍被加载并保留，便于切换。资源体积、解析时间和已保留的内存不因隐藏自动减少。本实验不以单卡几何比例推算 FPS。

## 实际渲染对照

在同一个 renderer 中，以 AB / BA 两种顺序比较完整和简化模型。每场景每状态合计 48 帧，共 12 组、288 个实际绘制帧；没有把复用画面计为测量帧。使用固定步进，逐帧核对选曲、旋转、抽取、镜头与归位副本数量一致。

环境：Windows、Edge 155 headless、NVIDIA GeForce RTX 5070 Laptop GPU / ANGLE D3D11，1280×720、DPR 1、原画质，阴影 2048、AO 32、景深与透射开启，音乐行距 0.62，未启用超级性能。对照页使用合成元数据与确定性频谱，不进行音频解码。

| 场景 | 绘制调用中位数：完整 → 简化 | 提交三角形中位数：完整 → 简化 | GPU 毫秒中位数：完整 → 简化 | 本次样本变化 |
| --- | ---: | ---: | ---: | --- |
| 阵列律动 | 75 → 45 | 4,185,945 → 3,952,071 | 3.536 → 3.860 | 耗时增加约 9.2% |
| 详情旋转 | 75 → 45 | 2,216,593 → 1,982,719 | 3.797 → 3.562 | 耗时减少约 6.2% |
| 连续切换与归位 | 220 → 100 | 4,044,699 → 3,109,203 | 5.155 → 5.038 | 耗时减少约 2.3% |

连续切换最多包含四个归位副本。提交三角形包含阴影、透射等多次提交，因此与单卡资产面数不同。GPU 时间来自 `EXT_disjoint_timer_query_webgl2`；缺失或 disjoint 时应记 null，本轮各组均取得有效样本。CPU 中位耗时分别为阵列 1.3→1.1 ms、详情 0.8→0.6 ms、归位 1.4→1.2 ms；小量样本受计时精度和系统负载影响，不能直接换算真实互动 FPS。

**当前结论：确认几何与提交开销下降，但 GPU 收益有限且并非所有场景都有改善。** 阵列样本反而变慢的原因尚未隔离，这一轮不能声称全面性能提升，也未做低配设备验证。视觉上歌曲卡片内部变为空白底板，精细圆环与雕刻不再出现，需要实际体验评估这一取舍。本轮保留为可关闭的实验，不转为 `basic`。

[结果摘要](music-model/results.json) 包含两种顺序的分组中位数；逐帧原始数据在本机 `.local/experiment-music-model-20261023/performance.json`。同机复现：启动 `npm run dev`，打开 `/reference/music-model.html`，在控制台依次执行 `await bench.prepare('detail', false); await bench.sample('detail', 24)` 与 `await bench.prepare('detail', true); await bench.sample('detail', 24)`；也可选择 `array`、`navigate`。页面没有自动循环绘制，每次采样必须先 prepare。

本轮未为此实验运行 GitHub Actions，未推送 GitHub、未合入 `basic`，也未更改固定基线标签。
