# Rhine Lab UI · 0.0.10 版本说明

- **版本**：0.0.10（基于 0.0.9 提交 `2aaa0b7`）
- **提交**：`47437e7`（音乐档案 ACCESS FILE 播放）
- **日期**：2026-10-09

## 更新内容

- 音乐模式下点击档案展示页的 `ACCESS FILE`、文件号按钮或键盘 Enter，会进入详情并播放当前选中的歌曲。
- 播放路径根据当前播放内核自动分流：浏览器内核使用 `MusicPlayer`，VLC 桥接使用 `MusicBridge`。
- 选曲使用 `MusicArchiveView.musicTracks[selected]` 对应的真实曲目 ID，不会把展示用的 `M-###` 档案编号传给播放器。
- 浏览器播放队列保持曲库顺序，播放失败沿用现有通知和文件授权提示；VLC 未连接时给出明确提示。
- 播放成功后继续复用已有背景音乐让位、频谱律动、播放状态和详情展示链路。
