# 0.1.4 · 音乐档案按动画设置起播

日期：2026-10-13（Asia/Shanghai）。本次为 0.1.3 后的小更新，独立备份并上传 GitHub。

两种播放策略共用完整曲库元数据索引，点击音乐档案后才准备所选音频，浏览器与 VLC 采用相同规则。

| 动画设置 | 更新后的行为 |
| --- | --- |
| 完整 | 完整索引 → 点击加载 → 文字黑条等待 → 音频就绪后揭示 → 揭示结束帧起播；等待期间保留场景与返回操作 |
| 减少（简化动画） | 完整索引 → 点击加载并显示文字 → 音频就绪即播放；取消黑条等待帧，不等待揭示结束或下一渲染帧 |
| 自定义 | 模型解密与正文揭示至少开启一项时沿用完整流程；两项均关闭时直接播放 |

直接播放仍需真实文件读取与内核准备。`SUPER PERFORMANCE` 只调整画质，不改变所选动画策略。直接播放失败时文字保持可读，保留错误与重试入口；返回、停止、换歌及内核切换使旧请求失效。当前请求的有效详情动效被关闭时立即清除黑条，并在就绪后仅起播一次；再启用完整动画从下一次打开档案生效。
