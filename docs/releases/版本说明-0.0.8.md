## 0.0.8 整合内容

0.0.8 以 0.0.6 音乐档案库为基础，整合封面稳定性、档案标题顺序和可调行距：

- **封面显示稳定性**：音乐封面写入卡片自身 `Frosted_Polymer` 前面板材质，以卡片深度和正面方向裁切，解决相邻卡片之间的封面遮挡与串图。
- **封面加载链路**：IndexedDB 封面 Blob 重新物化后再创建对象 URL，增加并发请求去重、异步失败退避和清理代际保护；VLC 桥接继续使用相同 `coverUrl()` 链路。
- **标题顺序**：音乐档案卡面和详情页采用作者/歌手为主行，歌曲名为次行，专辑继续作为补充信息展示。
- **音乐档案行距**：设置 → 本地音乐新增 `ARCHIVE SPACING` 滑条，范围 `0.62–8.00`，默认 `4.05`，实时预览并持久化到 `rhine-settings.musicRowSpacing`。
- **可见性计算**：可见性候选不再根据“当前是否音乐模式”动态切换行距；按支持范围生成固定保守候选，绘制阶段使用实际行距过滤。莱茵档案与 cinematic 开场固定保持 `0.62`。
- **拖动与惯性**：`trackCoordinate` 与 `trackPosition` 共用同一显式行距，保证音乐档案不同间距下拖动、惯性和滚轮选档仍按一行一份档案运行。
- **歌词范围**：歌词解析仍是后续范围，本版不新增歌词实现。
- **统一启动入口**：新增 `启动莱茵科技.cmd` 与 `npm run start:all`，统一编排网页、VLC 桥接、浏览器打开和退出清理；音乐目录可记忆，桥接端口与临时令牌自动交给网页并从地址栏移除。当前标签页通过 `sessionStorage` 短暂保留交接凭据以支持刷新，临时令牌不写入长期偏好。旧 `启动终端.cmd`（仅网页）和 `启动音乐服务.cmd`（仅桥接）保留兼容。

## 恢复与使用

```powershell
cd RhineLabUI
npm ci
npm run build
node scripts/fetch-vlc.mjs          # VLC 桥接需要时
启动终端.cmd
启动音乐服务.cmd "D:\你的音乐目录"   # VLC 桥接需要时
```

打开主界面后点击顶部「MUSIC 音乐库」进入音乐档案阵列；在 设置 → 本地音乐中选择分组方式并调节 ARCHIVE SPACING。点击「LOCAL MUSIC」打开曲库检索与播放面板。
