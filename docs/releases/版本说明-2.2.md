# Rhine Lab UI · 2.2 版本说明

- **版本**：2.2（基于 2.1 启动整合提交 `529e6e4`）
- **日期**：2026-10-09
- **来源**：`工作区/`

## 2.2 更新内容

### 音乐档案标题层级

- 音乐档案卡面改为歌曲名主标题、大字号；歌手与专辑作为次信息、小字号显示。
- 音乐详情页同步改为歌曲名 `h2` 主标题，歌手位于次级信息行；普通莱茵档案字段顺序不变。
- 长标题、长歌手名和窄屏详情继续使用现有截断、换行和滚动容器规则，避免文字溢出。

### 更多律动类型

- 保留 `legacy` 原版、`wave` 连续频谱、`lift` 层叠流波、`pulse` 响度律动和 `ripple` 波频律动。
- 新增 `groove` 宽频律动：以低频和低频瞬态为主，形成平滑、宽阔的鼓点起伏。
- 新增 `shimmer` 高频微光：以中高频细节为主，使用低幅空间相位变化，避免高频噪声造成卡片抖动。
- 新增视觉层 RhythmMotion 平滑：独立平滑低、中、高频和响度，加入有界的低频瞬态 accent；平滑使用 dt 无关的指数收敛，浏览器内核和 VLC bridge 共用同一视觉输出规则。
- 保持 `ripple` 为默认样式；既有用户已保存的样式选择不被覆盖。
- MUSIC REACTION 设置按钮在窄屏可换行，保留减少动态效果和关闭本地音乐律动时的归零行为。

### VLC 状态同步

- VLC 自动连接后，全局音乐帧每约 750ms 同步一次 bridge 播放状态，不再依赖音乐面板是否打开。
- 关闭音乐面板后，VLC 外部播放、暂停和停止仍能正确驱动频谱包络与档案律动。

## 2.3 追加内容（2026-10-09）

- 音乐模式下点击档案展示页的 `ACCESS FILE`、文件号或键盘 Enter，会进入详情并播放当前歌曲。
- 浏览器内核和 VLC bridge 使用当前 `MusicArchiveView` 的真实曲目 id，避免把 `M-###` 档案显示编号误传给播放器。
- 详情页、曲库面板和档案选择保持同一首歌曲的状态联动。
- `_verify-music.mjs` 2.3 回归为 **33/33**；VLC UI 回归保留 bridge 连接与直接播放检查，headless SwiftShader 起播超时单独记录为环境限制。
