# 开源发布准备

2026-10-10。以当前三维档案与本地音乐工程为发布内容，保留原作者署名、MIT 许可证和第三方资源的许可说明。

公开仓库：[LobbyuniQue/RhineLabUI-Music-Player](https://github.com/LobbyuniQue/RhineLabUI-Music-Player)。

## 内容与历史

- 源码、模型、Blender 源工程、文档、内置档案及验证工具纳入发布。
- 本机缓存、浏览器配置、临时曲库、私人录音、VLC 二进制、独立授权字体、依赖目录与构建产物排除发布。
- 音乐检查默认使用合成样本；真实音频只在显式设置 `RHINE_MUSIC_SAMPLE` 时读取。
- 个人绝对路径替换为相对路径或通用示例；历史版本内容与当时的测试数量保留。
- 原有 Git 历史含个人录音路径，因此公开分支使用脱敏当前源码的独立初始提交。本机原历史已通过 Git bundle 备份并校验，不推送旧历史与旧标签。
- 原文件和本机备份位于被忽略的 `.local/maintenance/20261010/`。公开 Git 历史只发布当前 `main`。

## 构建可移植性

移除从原作者托管站点自动恢复授权字体的逻辑。缺少 Novecento 时使用现有固定字形回退；本机存在该字体时仍校验 SHA256。Cloudflare 打包允许无授权字体构建，只复制实际存在的资源。
