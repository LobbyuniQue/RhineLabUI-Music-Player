## 0.0.6 变化：音乐档案库

0.0.6 把本地音乐曲库接入原有档案阵列，保留莱茵档案库并新增双模式切换：

- **双模式**：主界面新增「ARCHIVE 档案库 / MUSIC 音乐库」切换。莱茵档案与音乐档案分别保留选中记忆；音乐库为空时不强制切换。
- **动态分组列**：音乐库支持「按专辑」「按歌手」「按首字母」。列数等于实际分组数，阵列横向循环；列内为该组歌曲，保留拖动、上下切歌、左右切列、抽取详情、检索和模式切换。
- **音乐档案内容**：曲名、艺术家、专辑、年份、格式、时长、文件规格、曲号/碟号、流派等映射到既有档案 HUD、详情页、研究记录和动态 EXPORT 文本。
- **逐卡封面**：每首歌曲的封面对应其档案卡。新增 2048×2048 封面图集（128px tile）、逐实例 `archiveCover` 索引与共享实例矩阵；音乐库使用独立行距保证卡面净空，封面写入 `Frosted_Polymer` 前面板材质，按卡片深度裁切，不再跨卡片遮挡。封面异步从 IndexedDB 解码并批量刷新；无封面时使用品牌占位 tile。选中卡的正面 Canvas 标签以作者/歌手为主行、歌曲名为次行，并显示专辑。音乐档案行距可在设置中以 0.62–8.00 滑条调节，默认 4.05；莱茵档案及 cinematic 开场固定 0.62。
- **VLC 封面透传**：桥接扫描保留 year/genre/disc 与封面字节，新增令牌保护的 `/api/cover?id=` 端点；网页桥接曲目可通过同一 `coverUrl()` 链路显示封面。
- **歌词范围**：歌词明确推迟到 0.0.7，本版不解析 USLT/SYLT/Vorbis/©lyr 或外挂 `.lrc`。

## 恢复与使用

```powershell
cd RhineLabUI
npm ci
npm run build
node scripts/fetch-vlc.mjs          # VLC 桥接需要时
启动终端.cmd
启动音乐服务.cmd "D:\你的音乐目录"   # VLC 桥接需要时
```

打开主界面后点击顶部「MUSIC 音乐库」进入音乐档案阵列；设置 → 本地音乐中选择「按专辑 / 按歌手 / 按首字母」。点击「LOCAL MUSIC」仍可打开曲库检索与播放面板。歌词功能计划在 0.0.7 增加。
