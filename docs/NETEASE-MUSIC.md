# 网易云音乐歌单与账号

此功能位于 `experiment/netease-playlists` 实验分支，沿用 0.1.5 的本地曲库与播放器。

## 查看公开歌单

打开音乐面板，点击「网易云歌单」，粘贴歌单 ID、官网歌单地址或包含网易分享短链的文字。曲目按官网顺序列出，点击曲名打开网易云音乐的歌曲页。页面同时显示已读条数和官方公布的总数。遇到仅部分公开的歌单，可以通过歌单标题旁的链接查看官网。

本地启动器、`npm run dev`、`npm run preview` 和 `npm run preview:dist` 都带有公开歌单读取服务。Cloudflare Pages 的 Git 构建可以使用仓库中的 `functions/api/netease/playlist.js`。仅复制静态文件到普通网页空间时，需要额外提供该服务。[Cloudflare Pages Functions 路由说明](https://developers.cloudflare.com/pages/functions/routing/)

## 连接自己的网易云账号

1. 在本机项目目录运行 `npm run netease:install`。该命令将网易官方 CLI 0.1.7 安装到项目的 `.tools/netease-cli`。
2. 运行 `npm run netease:configure`，在网易官方终端向导中输入自己获批的 App ID 和私钥。应用资质和接口范围以网易开放平台控制台为准。[网易官方配置指南](https://github.com/NetEase/skills/blob/master/ncm-cli-setup/SKILL.md)
3. 使用本地启动器打开音乐面板，进入「网易云歌单 → 我的账号」。点击登录并按网易提示授权。如果需要在终端扫码，可运行 `npm run netease:login`，完成后回到面板刷新登录状态。
4. 从下拉列表选择「我喜欢的音乐」或自己创建的歌单，每页读取 30 首。「我喜欢的音乐」只列一次。查看个人歌单时会保留本地文件夹预设和当前播放队列。

账号操作只接受本机浏览器访问本机服务。公开部署提供公开歌单读取。私钥配置和扫码授权由网易官方 CLI 管理，账号接口响应标记为 `no-store`。选择「退出本机网易登录」并确认后，应用会退出本机官方 CLI 的会话，其他共用该会话的工具也需要重新授权。单纯关闭音乐面板可以保留登录。

## 会员与歌曲音质

会员信息采用网易当前账号资料中的 `vipDetail`。界面区分有生效会员、当前无生效会员、平台未提供足够信息。历史会员、账户等级和歌曲付费标签不能单独证明当前权益。[网易账号资料接口](https://developer.music.163.com/st/developer/document?docId=8ed9b2f123e44923979596a277733421)

打开自己歌单中一首歌的「音质」。当网易歌单接口报告该曲可播并给出 `plLevel` 时，面板提供「自动」以及这一已确认的最高可播档。取值依据是当前账号对当前歌曲的权限；不同曲目可以得到不同结果。网易另有逐档授权接口，需以应用实际开放的能力为准。[网易歌单曲目接口](https://developer.music.163.com/st/developer/document?docId=200b1217d6634259b3d665e330bd7dd0) · [网易逐曲音质接口](https://developer.music.163.com/st/developer/document?docId=548179f7ecbc417d8acd35d604aea3c9)

本机服务确认保存后，重新打开同一首歌可以读回选择；改选「自动」可清除偏好。偏好保存在当前服务进程中，换账号、退出或重启服务时清除。音质授权缓存有效期为五分钟，过期后重新读取歌单即可更新。明确不可播和平台尚未确认的曲目分别显示原因。

点击歌曲会前往网易官方页面，官网实际播放的音质由官网控制。应用内串流、音频下载和离线会员播放属于后续播放接入范围。

## 本机验证记录

2026 年 11 月 22 日，在静音浏览器中使用已扫码授权的真实账号，确认面板能显示当前会员状态，并分别读取红心歌单和自建歌单的首批 30 首。打开一首有可播音质的歌曲，选择网易返回的档位，再次查询时读回相同选择。另一首被明确标为不可播的歌曲没有提供可选档位。验证期间浏览器音频播放调用次数为 0。

`npm run check` 包含账号、权益、公开歌单和本机 HTTP 接口检查。完成 `npm run build` 后，可用 `npm run test:e2e:netease` 在隔离浏览器中检查登录过期、音质选择和退出确认等交互；该命令使用模拟账号。真实账号联调保留了原有登录会话。
